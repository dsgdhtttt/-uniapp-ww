# 洗车系统源码全开源+uniapp前端 

源码地址：ym7k.com/17823/

这套全开源洗车管理系统搭配 Uniapp 多端前端，打通车主线上预约、门店接单、技师服务、订单结算、会员管理全流程，适合社区洗车店、综合汽修门店、自助洗车站点、上门洗车服务使用。Uniapp 前端支持 H5、小程序多端访问，车主不用下载 APP，门店管理者和技师也可以移动端操作，搭配电脑管理后台，数据实时互通，告别纸质登记、微信零散接单的管理方式。


车主端是系统面向客户的核心入口，功能围绕预约下单设计。用户进入前端页面可以查看门店位置、营业时间、服务项目与对应价格，项目区分普洗、精洗、内饰清洗、打蜡、镀膜等不同套餐，图文清晰展示。支持自主选择到店洗车或者上门洗车，选定服务后挑选可预约时段，提交预约订单。系统会自动锁定时段，避免同一时间段订单扎堆拥堵。下单后可以在线支付，也支持到店结算，订单状态实时更新，车主能够随时查看待接单、服务中、已完成等进度，服务结束后还可以对本次洗车进行评价打分，帮助门店收集客户反馈。

订单与技师派单体系，适配门店日常运营。车主提交预约订单之后，后台实时收到提醒，管理员可以手动接单，也可以开启自动接单模式。订单接单后可指派对应技师，技师在移动端接收工单，查看客户信息、服务项目、备注要求。服务完成后标记完工，支持上传洗车前后对比照片留存记录。所有订单按时间、服务类型、支付状态分类管理，便于核对营收，杜绝漏单、错单问题。

后台拥有完整的数据和门店配置能力。管理员可以维护服务分类、套餐价格、门店介绍、营业时间，支持上架、下架服务项目。库存板块可以管理洗车耗材，记录耗材领用消耗，设置库存预警，耗材不足及时提醒采购。系统自带统计看板，自动汇总每日订单、营收金额、会员新增、优惠券核销等数据，直观展示门店经营情况，所有订单、会员数据都支持导出表格，用于对账存档。权限可以分开设置，老板、收银、技师分配不同操作权限，保障数据安全。

依托 Uniapp 的特性，前端可以一套代码适配多个访问入口，方便门店在不同渠道投放。整套源码全开源无加密，部署在自有服务器，数据自主掌控，还能按需拓展功能，比如增加车辆档案、保险代办、汽修项目对接、自助扫码洗车等模块![Uploading 2268bf78025ddc31c4b25a7b21b6b2ad.png…]()



总的来说，这套洗车系统把客户预约下单、会员营销、工单派单、技师管理、经营统计整合为一体，线上引流接单，线下规范服务流程，帮助洗车门店标准化运营，提升接待效率，降低人工登记成本。
